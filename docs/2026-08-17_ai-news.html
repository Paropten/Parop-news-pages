今日の便利Tips

Windows 11

Win + X で管理メニューをすぐ開く

何が便利か：ターミナル、デバイスマネージャー、イベントビューアーなどへ素早く移動できます。

手順：Win + X を押し、表示されたメニューから目的の項目を選択。

注意点：管理者権限が必要な操作は、影響範囲を確認してから実施します。

活用メモ：トラブル調査時に設定画面を探す時間を短縮できます。

Excel

Ctrl + Shift + 矢印でデータ範囲を一気に選択

何が便利か：長い一覧の末尾までマウスでスクロールせず選択できます。

手順：起点セルを選択 → Ctrl + Shift + ↓ または → を押す。

注意点：途中に空白セルがあると、その手前で選択が止まります。

活用メモ：大量データのコピー、書式設定、確認作業に便利です。
