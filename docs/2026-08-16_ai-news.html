夏季休業中の図書館システム停止、サービス単位の事前案内が重要

公開日：2026年6月30日｜出典：早稲田大学図書館

https://www.waseda.jp/library/news/2026/06/30/29731/

要点

  • 古典籍総合データベースは8月14日6時から8月15日9時まで停止。
  • 各種図書館サービス申請フォームは8月3日17時から8月17日14時まで停止予定。
  • 同じ「図書館サービス停止」でも、サービスごとに期間が異なるため個別記載している。

活用メモ：メンテナンス案内テンプレートに、停止機能・開始時刻・終了予定・代替手段・復旧確認欄を持たせると再利用しやすい。

新規性メモ：現在も一部サービスの停止期間中であり、運用上の参考価値がある。

信頼度メモ：公式図書館サイトを確認。

公開日：2026年7月28日｜出典：デジタル庁

https://www.digital.go.jp/procurement

要点

  • デジタル庁の企画競争に「自治体からの照会事務の自動化などの国・地方AI共通サービスに関する実証事業」が掲載されている。

活用メモ：問い合わせ削減では、AIにすべて答えさせず、定型質問は自動回答、判断が必要な内容は有人窓口へ引き継ぐ段階設計が現実的。

新規性メモ：行政AIの適用範囲が庁内支援から国・地方間の照会事務へ拡大する動きとして注目。

信頼度メモ：デジタル庁の公式調達情報を確認。

ユーザポータル構築メモ

会員制ポータルで重要なのは、画面上で非表示にすることと、データ自体へのアクセスを制限することを分けて考えることです。Softrの公式セキュリティ資料では、ユーザーグループや条件付きフィルターをサーバー側で評価し、対象外レコードを取得しない設計を案内しています。

  • 実務に使える示唆：権限はページ、ブロック、レコードの3段階で確認する。
  • 確認したい論点：公開用データと会員限定データを同じテーブルへ混在させない。
  • 次に検討できること：一般利用者、施設担当、管理者などのテストアカウントで表示範囲を確認する。

参考：https://docs.softr.io/security/softr-app-security

今日の便利Tips

Windows 11

Win + R からよく使う管理画面を直接開く

何が便利か：設定画面を何段階もたどらず起動できます。

手順：Win + R → 例として services.msc を入力 → Enter。

注意点：サービス停止や設定変更は影響範囲を確認してから実施します。

活用メモ：eventvwr.msc でイベントビューアー、appwiz.cpl でプログラム一覧も開けます。

Excel

Ctrl + 1 でセルの書式設定をすぐ開く

何が便利か：表示形式、配置、罫線などをまとめて調整できます。

手順：対象セルを選択 → Ctrl + 1 → 必要なタブを設定。

注意点：日付や時刻は見た目だけ変えても内部値は変わりません。

活用メモ：数値の桁区切り、文字列扱い、時刻表示の確認に便利です。
