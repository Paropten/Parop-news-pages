図書館システム・保守運用

大阪市立図書館、ホームページと利用アプリを含むサービス影響範囲を事前案内

公開日：2026-08-20 ／ 出典：大阪市立図書館

https://www.oml.city.osaka.lg.jp/key/2026/1002_2026081401.html

  • 8月19日20時45分から21時まで、ホームページのメンテナンスを実施。
  • 蔵書検索、予約、貸出・予約確認、パスワード再登録、各種フォーム、利用アプリ、デジタルアーカイブなど幅広いサービスを影響対象として列挙。
  • 一時的に利用できない場合は時間を置いて再利用するよう案内している。
実務ポイント：保守案内は「システム停止」と一括表現するより、利用者から見える機能名で影響範囲を列挙すると、問い合わせを減らしやすくなります。

活用メモ：メンテナンス告知テンプレートに、日時、対象機能、代替手段、復旧後の確認方法の4項目を固定すると運用しやすくなります。

新規性メモ：8月20日公開。前夜実施の保守内容と影響範囲が具体的に整理されています。

信頼度メモ：大阪市立図書館公式サイト。

個人情報保護・公共IT

行政機関等向け個人情報保護ガイドライン、7月改正版を公開中

改正：2026-07 ／ 出典：個人情報保護委員会

https://www.ppc.go.jp/personalinfo/legal/guidelines_administrative/

  • 行政機関、地方公共団体、独立行政法人等における個人情報の適正な取扱いを示すガイドライン。
  • 2026年7月の一部改正版と7月31日付の新旧対照表が公開されている。
  • 委託先を含む個人情報の取扱いが対象となり、公共サービスの外部システム利用でも確認が必要。
実務ポイント：会員制ポータルやAIチャットでは、画面のアクセス制御だけでなく、委託先、ログ、保有期間、削除、再委託まで含めて個人情報の流れを整理する必要があります。

活用メモ：新しい外部サービスを導入する際は、「何を送るか」「誰が見られるか」「どこに残るか」「いつ消すか」を事前チェック項目にすると漏れを防ぎやすくなります。

新規性メモ：2026年7月の一部改正を反映。公共向けポータルやAIサービスの運用確認にも関係します。

信頼度メモ：個人情報保護委員会公式ガイドライン。

ユーザポータル構築メモ

実務に使える示唆：利用者ポータルでは、ログイン可否だけでなく、表示対象レコード、操作権限、ログ保存、委託先でのデータ保持までを一続きの権限設計として確認することが重要です。

確認したい論点：団体単位のデータ分離、管理者例外権限、退会時のデータ処理、問い合わせ履歴の保存期間、外部AIサービスへ送信する情報の範囲。

次に検討できること：権限表に「閲覧・作成・編集・削除」に加えて「ログ閲覧」「データ保存先」「削除条件」の列を追加する。

今日の便利Tips

Windows 11

Win + Ctrl + D で新しい仮想デスクトップを作る

何が便利か：作業中の画面を閉じずに、別の作業用デスクトップをすぐ用意できます。

手順：Win + Ctrl + Dを押して新しいデスクトップを作成し、Win + Ctrl + ← / →で切り替えます。

注意点：アプリ自体が別ユーザーで起動するわけではなく、同じWindowsセッション内の画面整理機能です。

活用メモ：通常業務、調査作業、オンライン会議などで画面を分けると整理しやすくなります。

Excel

Ctrl + Space で列全体をすばやく選択

何が便利か：列幅変更、書式設定、コピーなどを行う前にマウスで列見出しを探す手間を減らせます。

手順：対象列のセルを選び、Ctrl + Spaceを押します。

注意点：テーブル内では最初の操作でデータ部分のみが選択される場合があります。

活用メモ：列単位の書式統一や削除前の確認に便利です。
